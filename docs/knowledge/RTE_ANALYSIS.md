# RTE removal and residual shared-state review

The original hand-written `RTE/RTE.c/.h` exposed variable aliases, HAL/RTOS call wrappers and runnable wrappers. It did not schedule tasks or provide locking, queues or generated AUTOSAR semantics. The 2026-10-18 APP migration removed these sources and their CubeIDE entries. Legacy task loops now call component MainFunctions explicitly, and sender/receiver wrappers were replaced with direct owner values; HAL and RTOS wrappers call their underlying APIs. `Modernization/tests/check_app_integration.py` checks that no APP source or CubeIDE source entry refers to RTE.

The migration preserved each wrapper's assignment/call behavior at source level. Several components still access each other's exported globals, including values shared with FreeRTOS tasks and timer/interrupt callbacks. This remains a runtime review limitation. The current migration adds coherent COM snapshots, protected hardware CRC, typed DEM access and a bounded UART ISR/task FIFO; it does not assert a complete rewrite of legacy task concurrency. Full Cortex-M builds and native tests now pass; physical application regression remains unexecuted. See [current closure](../modernization/G26_IMPLEMENTATION_CLOSURE.md).
