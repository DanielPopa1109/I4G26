# G26 changes and external changeset boundary

The source integration status is in [EXTERNAL_INTEGRATION_DEPENDENCIES.md](EXTERNAL_INTEGRATION_DEPENDENCIES.md). ZGW now has a dedicated 0x709 return route and 0x710 transmit channel for G26; its response flow-control address is 0x41. The RepoCM5 and ZGW FCD copies now have a G26 0x55 profile, contiguous HEX image checks, APP/FBL identity handover, target-specific update sequence and strict response handling. These are source and host-test changes, not a deployed gateway or exercised ECU session.

G26 locally implements the configured BSW, persistent diagnostics and independent resident/SRAM update paths. See [implementation closure](../modernization/G26_IMPLEMENTATION_CLOSURE.md), [protocol](../bootloader/PROGRAMMING_PROTOCOL.md) and [hardware dependencies](../can/PHYSICAL_HARDWARE_DEPENDENCIES.md). Proposed commands and status remain disabled; the MCP2515 board guard and resident-FBL updater interlock remain off. Deployed interoperability and power-loss recovery are unverified.
